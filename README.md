The current release is a controlled Windows x64 pilot. No Mac installer is published. Ask your internal operator for approved certificate trust, a dedicated pilot launcher and signed local Microsoft login provisioning before installing. A public download does not grant company access. The user guide covers the feature areas in 0.1.10, including conditional database, SharePoint and AI functionality. AI-provider subscriptions or usage are separate and optional.

Development source is maintained separately in a private repository. This public repository contains distribution documentation; Releases contain audited installers and update metadata. Keep latest.yml, release.json and blockmaps for the updater. GitHub-generated Source code archives contain this public repository at their tag, not the private source repository; existing v0.1.10 archives contain only the README present when that tag was created.

Never upload credentials, private keys, company configuration, signed company provisioning, user profiles, operational documents or development source here. Report sensitive support details only through your approved internal channel.
